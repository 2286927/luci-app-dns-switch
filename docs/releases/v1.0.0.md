# v1.0.0

把全屋 DNS 在 AdGuardHome 和运营商 DNS 之间一键切换，并且在 DNS 出任何事的时候自己回到「能解析」的状态。

首个可发布版本。46 条真机回归（4 轮）全通过，apk 在 R68S / ImmortalWrt 25.12 上完成装 / 用 / 卸 / 重启四种状态验证。

## 装机

```sh
# 25.12 及以后（apk）
apk add --allow-untrusted luci-app-dns-switch_1.0.0-r1.apk

# 23.05 / 24.10（ipk，走 Actions 的 build 线）
opkg install luci-app-dns-switch_1.0.0-r1.ipk
```

装完刷新 LuCI，菜单在 **服务 → DNS 网关切换**。

本包架构无关（`LUCI_PKGARCH:=all`），一个包能装在所有架构上。

## 装完先改这三项

出厂值按作者网段（`172.16.1.0/24`）写的，换成你自己的网络只需改「高级参数」里三项：

| 项 | 出厂值 | 说明 |
|---|---|---|
| AdGuardHome 地址 | `172.16.1.2` | 跑 ADH 那台设备的局域网 IPv4。填错的表现是切换被拒绝，不是断网 |
| 管理端口 | `3030` | ADH 的网页端口（不是 53），用来确认进程真的活着 |
| 备用 DNS IPv4 | `172.16.5.5` | ADH 不可用时 DHCP 下发兜底的地址，留空表示只下发路由器自己 |

## 本版修掉的四个缺陷

| 编号 | 现象 | 根因 |
|---|---|---|
| F1 | 改完参数后，任何一次漂移自愈都会把下发改回旧值，且 `applied_sig` 记的也是旧值，不会自我纠正 | 守护进程把配置缓存到启动那一刻，整个生命周期只读一次。抽 `reload_cfg()` 在 tick / init / 快照回滚入口重读 |
| F2 | 「改坏参数后回滚」是假动作，回滚后参数仍是改坏后的值 | `snap_restore` 只还原 `/etc/config/dhcp` 与 nft 片段，没还原 `dns_switch` 的 settings 段 |
| N1 | 缺 `curl` 时探测判负，进而触发 failover，把全网降级到运营商 DNS | 一个只影响探测精度的可选包不该有这种杀伤力。改为缺 curl 只降精度，不阻断、不降级 |
| N2 | `dns-switch rescue` 后页面仍显示绿色「正在使用 AdGuardHome」，实际已回运营商 | rescue 只写 `settings.mode=off`，没写 `status.effective`，守护又已停止，没有 tick 纠正 |

## 未实现（不要期待）

- **上游链抽象**：不支持多级探测、手动锁定某一级
- **效果统计**：没有拦截量、平均解析耗时
- **审计**：不记录谁切的、来源 IP
- **ucode 重写 + ubus 对象**：仍是 POSIX sh 单文件实现，`ubus call dns-switch status` 不可用

## 已知限制

- 仅支持 **fw4 / nftables**（OpenWrt 22.03+）。fw3（iptables）固件上装了只会「看着成功、其实不生效」
- 需要 **busybox 带 `flock` applet**，并发锁靠 `flock -n`
- **curl 是精度增强不是硬依赖**：缺它探测降一档，主卡片会显示提示，装上后一分钟内自动消失
- **仓库里的脚本 mode 是 644**（网页上传不保留执行位）。CI 构建时会自动 chmod，但**本地 clone 后直接 `make` 会打出 644 的包**，装上去 `dns-switch` 跑不起来。本地构建前先执行：
  ```sh
  chmod +x luci-app-dns-switch/root/usr/bin/dns-switch \
           luci-app-dns-switch/root/etc/init.d/dns-switch \
           luci-app-dns-switch/root/etc/uci-defaults/99-dns-switch
  ```
- `dns-switch status` 的「ether 豁免: N 条」读的是磁盘上的 nft 片段，在「刚切换完、nft 正在重建」的那一瞬间可能显示 0，实际规则是好的（下次刷新即正确）
- 快照回滚会连同 `dns_switch` 参数一起还原 —— 这是 v1.0.0 的行为变更，与早期测试版不同
